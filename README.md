# Student Support AI Chatbot 🤖

A simple rule-based AI chatbot built entirely in Python using Google Colab. This project acts as an automated helpdesk for students to resolve common college-related queries instantly without needing any separate web frontend.

---

## 🚀 Features
* **Interactive UI:** Built using Python's `ipywidgets` inside Google Colab for a clean chat-like experience.
* **Instant Answers:** Handles frequent student queries regarding admissions, fee payments, exam schedules, and library timings.
* **No Frontend Needed:** Runs completely within the Jupyter/Colab notebook environment.

---

## 🛠️ Tech Stack
* **Language:** Python 3
* **Environment:** Google Colab
* **Libraries:** `ipywidgets`, `IPython`

---

## 📥 How to Run the Project
1. Run all the code cells in the notebook (`Shift + Enter`).
2. Type your question in the text box that appears and press **Enter** to chat with the bot!

---

## 💡 Example Queries You Can Ask
* *"What are the admission details?"*
* *"Tell me about the fee submission deadline."*
* *"What is the library timing?"*
* *"When is the exam schedule released?"*
